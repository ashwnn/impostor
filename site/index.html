Party word game · runs on your LAN

Impostor

Everyone gets the same secret word — except one player, who only gets a hint. Trade clues, argue out loud, then vote them out. One machine hosts; every phone and laptop on the network joins from a browser.

Get it on GitHub
01

Everyone writes a word

Each player secretly submits a candidate word and a hint before the round can start. The chosen word is never one that all players wrote.

02

One player is the impostor

The crew sees the word. The impostor sees only the hint — and nobody who wrote the chosen word can be picked as impostor.

03

Clues, talk, vote

Clues stay hidden until everyone submits, then reveal together. One vote each. Unique plurality on the impostor means the crew wins.

Run it in one minute

git clone https://github.com/ashwnn/impostor.git
cd impostor
npm install
npm start

The server prints a LAN link like http://192.168.1.5:8787. Share it with everyone at the table — no accounts, no internet dependency, no cloud. Rooms live in memory on the host and expire after 24 hours idle.

Host word bank

Import a JSON list of word/hint pairs for mixed-pool rounds.

Private roles

Secrets are per-player, server-side. The impostor never receives the word.

3–16 players

One impostor per round, hidden clues, one vote each, instant results.
